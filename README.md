# Ghi chú cá nhân — R1

Ứng dụng ghi chú cá nhân chạy cùng Laravel 13, PHP 8.5, MySQL 8.4, Blade,
Alpine.js 3, JavaScript modules, CSS riêng và Vite 8. Giao diện và thông báo
người dùng là tiếng Việt; nội dung ghi chú nhận Unicode và giữ nguyên thụt dòng.

Hướng dẫn đầy đủ, gồm cấu hình database, kiểm thử và các phần được hoãn, nằm
trong [`Readme.txt`](Readme.txt). Bằng chứng chạy kiểm thử/browser nằm trong
[`docs/verification.md`](docs/verification.md).
