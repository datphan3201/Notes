# /dashboard — Today, This week and Activity

[Documentation home](../../README.md) · [All routes](../../reference/routes.md)

These are workspace sections on one URL. Their facts come from server projections; browser cards/heat levels do not create a productivity score.

Today and This week use the existing split layout: the checklist and its progress summary occupy the main column, while supporting cards sit alongside it on desktop and stack on small screens. Today includes Habits and recent Activity; This week includes Milestones, Habit targets and the Weekly activity chart. Current focus is retired. Recent Activity balances the total with a coloured 30-day calendar and legend; the full-year Activity tab remains available. Weekly activity has readable columns, daily counts and a contribution total, distinct from the checklist completion percentage. Habits can be checked in directly from Today. The chosen roadmap is saved per account and appears directly below the header; an unset choice invites selection. Account-local daily selections are independent of deadlines and work intervals; automatic membership alone does not select the week.

### Today progress and checklist

**Trace ID:** `dashboard.today`

Today combines account-local daily selections, matching due/start/occurrence dates, overlapping work intervals and recent unfinished overdue work. Explicit daily selections remain visible even when a Task otherwise qualifies for History. Today and Weekly task rows use the existing versioned Complete/Reopen flow. Current focus has been removed; Task completion/editing remains on the actual Task controls.

### This week and weekly summary

**Trace ID:** `dashboard.week`

The This week tab places its progress summary and Weekly tasks checklist in the main column, with Milestones/Habit targets and a Weekly activity chart in the side column. The chart shows the sum of daily contribution facts, seven readable weekday labels and per-day counts; zero dates have no green fill, and the account-local current date is highlighted. Column heights are relative to the largest count in that week, independently of checklist completion percentages. Today no longer contains any week content. Task rows support completion and Add for today without moving/removing weekly membership or changing Task dates/status. Two independent native selects sort by Importance (descending) or Scheduled time (earliest first, unscheduled last), and filter All/Not started/On progress/Blocked/Completed. Sorting/filtering does not rewrite stored order, membership or weekly percentage denominators; the count badge shows filtered/total while a status filter is active. The tab lists the whole selection (Today previews stay at four rows). The row action is a compact + icon with Add for today as its native hover tooltip and accessible name; already-present Tasks show a check mark. Filtering never changes the full selected denominator.

### Roadmap below the header and account selection

**Trace ID:** `dashboard.roadmap`

The roadmap strip is directly below the page header, before the section tabs. A native select offers owned unarchived Goals, including child/completed Goals. Selection is stored per account; unset/cleared/archived choices show an invitation rather than automatically picking the highest-importance Goal. The preview shows up to six Milestones or the selected Goal link. The connector after each node fills green in proportion to that Milestone's own progress (Completed is 100%, otherwise finished Tasks over its Tasks); a node is solid when complete and outlined green when partly done. Progress is a factual Task ratio, not a prediction. Owner-locked PATCH validates exactly goal_id (owned UUID or null), returns 404 for foreign/archived IDs and does not modify Goal versions or planning facts. Stale Dashboard refreshes and obsolete preview requests cannot replace a newer choice. The same selection is the Goals page Main goal (GET /api/v1/dashboard/roadmap reads it).
