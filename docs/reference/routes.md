## API and private worker

Paths are declared patterns; `{kind}` accepts only the eight models listed in `planning.MODELS`. Worker paths belong to `planner.worker_api:app`, which is separate from the Render public API. Authorization/body requirements must be read at the handler and its dependencies; this list does not imply anonymous access.

FastAPI also supplies `/openapi.json` and `/redoc`; `/docs` is disabled in production. Those framework routes are configured by the FastAPI constructor and are outside the decorator table. Next.js supplies `/manifest.webmanifest` and `/icon.svg`, and serves public assets.
